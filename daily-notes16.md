# Gün 16

Bugün frontend ile ASP.NET Core Web API arasında bağlantı kurdum.
API isteklerini yönetmek için apiClient.js dosyasını oluşturarak fetch tabanlı bir yapı geliştirdim.
Görev listeleme, ekleme ve silme işlemlerini doğrudan API üzerinden çalışacak şekilde düzenledim.
Tüm görevleri silmek için yeni bir endpoint oluşturdum ve frontend tarafına entegre ettim.
CORS ayarlarını yapılandırarak frontend ile backend arasındaki iletişim sorununu çözdüm.
Projeyi localStorage yerine veritabanı tabanlı çalışan bir yapıya dönüştürmüş oldum.
