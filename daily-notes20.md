# Gün 20

Bugün TaskBoard projesinin son geliştirme ve kontrol aşamalarını tamamladım. Backend ve frontend arasındaki bağlantılar tekrar kontrol edilerek görev listeleme, ekleme, güncelleme ve silme işlemlerinin doğru çalıştığı doğrulandı.

API tarafında görev filtreleme, arama ve sayfalama özellikleri test edildi. GET /api/tasks endpointinin query parametreleri ile doğru sonuç döndürdüğü kontrol edildi ve frontend tarafında filtrelerin API üzerinden çalışması sağlandı.

Kullanıcı giriş sistemi, yetkilendirme yapısı ve API bağlantıları test edildi. Frontend ile backend arasındaki iletişimde oluşan CORS problemi giderildi ve uygulamanın demo akışı çalışır hale getirildi.

Görevlerin tamamlanması, silinmesi ve tüm görevlerin temizlenmesi işlemleri test edilerek uygulamanın temel CRUD özellikleri tamamlandı. Ayrıca proje genelinde son kontroller yapılarak eksik noktalar belirlendi.

README dosyası final duruma getirildi. Projenin amacı, kullanılan teknolojiler, kurulum adımları, çalıştırma komutları ve mevcut özellikler dokümante edildi.

Bugün yaptığım çalışmalar sonucunda bir full-stack uygulamanın frontend, backend, API, veritabanı ve kullanıcı yönetimi süreçlerini birlikte yönetme konusunda deneyim kazandım.
